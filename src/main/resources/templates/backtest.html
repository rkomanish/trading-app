ℹ How does the backtest work? (click to expand)
Step-by-step:
1. Loads your real 5m Nifty candles from the database for the date range you enter.
2. Splits them into N windows (e.g. 4 windows of equal length).
3. In each window: replays every candle one-by-one as if it's live — asks the strategy "do you want to trade?"
4. If yes: enters at next bar's open price, exits when SL / target / time-limit (50 bars ≈ 4 hours on 5m) is hit.
5. P&L = (exit − entry) × 75 (1 lot Nifty = 75 units, each 1 Nifty point = ₹75).
6. A strategy is PROMOTABLE if it shows positive expectancy in the majority of windows.

⚠ Data requirement: Need at least 60 trading days for reliable results. With less data, use Windows = 2 (not 4). To import more: go to Import Data tab → Symbol: ^NSEI, Interval: 5m, Period: 60d.
